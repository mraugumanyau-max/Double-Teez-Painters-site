# Double Teez Painters Website

## Project Overview

The **Double Teez Painters Website** is a web-based project designed to provide an online presence for Double Teez Painters. It contains several pages that allow visitors to explore information about the business, its services, features, and contact details.

The website is built using HTML, CSS, and JavaScript, with supporting images and libraries.

## Website Pages

The project contains the following pages:

- **Home (`index.html`)** – Main landing page.
- **About (`about.html`)** – Information about the business.
- **Services (`service.html`)** – Services offered.
- **Features (`feature.html`)** – Website features.
- **Appointment (`appoinment.html`)** – Appointment page.
- **Contact (`contact.html`)** – Contact information.

## Technologies Used

- HTML5 – Website structure.
- CSS3 – Website styling and layout.
- JavaScript – Website functionality and interactivity.
- SCSS – Stylesheet development.
- Bootstrap and supporting libraries, where included in the project.

## How to Run the Project

1. Clone or download this repository.
2. Extract the project folder if downloaded as a ZIP file.
3. Open the project folder.
4. Open `index.html` in your web browser.

You can also use Visual Studio Code with the Live Server extension to run the website locally.

## Installation

No Python environment, database, or backend server is required to view the website in a browser.
